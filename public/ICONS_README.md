# PWA Icons

Please add the following icon files to the `/public` directory:

- `icon-192.png` - 192x192 pixels
- `icon-512.png` - 512x512 pixels

These icons should feature a lock or helmet design with the app's blue theme color (#2563eb).

You can create these icons using any design tool or online icon generator.

For now, the app will work without these icons, but they are recommended for a complete PWA experience.
